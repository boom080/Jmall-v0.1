# 6.2 Jrunmall 简历材料整理

## 综合项目描述

使用 AI Agent 辅助完成多个端到端项目开发与整理，覆盖微信小程序、Web 电商、Java 后端、Python AI 服务、RAG 知识库、测试与文档。项目实践中将需求拆解、代码实现、接口联调、自动化测试、README/运行文档和 GitHub 上传安全检查串联起来，重点沉淀了从业务闭环到 AI 应用增强的完整开发流程。

## Jrunmall 单独项目描述

Jrunmall 是一个本地电商 AI 应用项目，基于 Java/Spring Boot 电商后端、Vue3 用户端与商家端、Python FastAPI AI 服务、MySQL/Redis/PostgreSQL/pgvector 和 Docker Compose 构建。项目已实现用户端商品浏览、购物车、下单、模拟支付、订单查询，商家端商品管理、订单查看、知识库管理和 AI 文案生成，并通过 Java AI Adapter 与 Python RAG 服务完成知识库 chunk 检索、引用来源返回和多模型配置。

## Java 后端岗位版

项目名称：Jrunmall 电商 AI 文案生成与 RAG 知识库系统

技术栈：Java、Spring Boot、MyBatis-Plus、MySQL、Redis、PostgreSQL、pgvector、Docker Compose、JUnit、Python FastAPI、Vue3。

项目描述：基于 Java 主业务服务构建本地电商闭环，并接入 Python AI/RAG 服务实现商家端商品文案生成。项目不是线上商用系统，主要用于本地开发、技术实践和面试展示。

项目职责：

- 设计并整理用户端注册/登录、地址、商品、购物车、下单、模拟支付、订单查询等业务链路。
- 维护 `gulimall-product`、`gulimall-member`、`gulimall-order` 等 Java 模块的数据边界与本地启动方式。
- 通过 Java AI Adapter 封装 AI 文案生成、模型选择、知识库列表和 txt 上传转发接口。
- 将普通订单与秒杀订单分库/服务边界整理为 MySQL + Redis Streams 的本地闭环。
- 编写并整理 Java product、AI adapter 单元测试与本地运行文档。

项目亮点：

- 将课程型商城代码整理为 Jrunmall 本地电商业务闭环。
- Java 后端与 Python AI 服务分层，避免 AI 调用逻辑侵入商品业务。
- RAG 响应保留 `response_source`、`usedChunks`、`citations`，便于验证检索来源。

## AI 应用开发岗位版

项目名称：Jrunmall 商家端 AI 文案生成与 RAG 知识库

技术栈：Python、FastAPI、SQLAlchemy、PostgreSQL、pgvector、openai-compatible embedding、Qwen、DeepSeek、Java AI Adapter、Vue3、Pytest。

项目描述：围绕电商商家端场景实现 AI 文案生成能力，支持知识库创建、txt/PDF/文本导入、chunking、embedding、pgvector 检索、prompt 证据拼接和引用来源展示。

项目职责：

- 实现和整理 Python `ai-services` 的知识库、chunking、embedding provider、RAG retriever 和商品文案 workflow。
- 支持 mock embedding 与 openai-compatible embedding 两种模式，便于无 Key 测试和真实语义检索切换。
- 通过 PostgreSQL + pgvector `vector(1024)` 作为目标结构保存 chunk embedding。
- 在生成结果中返回 `response_source`、`usedChunks`、`citations`，用于证明 RAG 命中来源。
- 编写 Pytest 覆盖 chunking、txt/PDF 导入、embedding provider、pgvector repository、RAG 文案生成等逻辑。

项目亮点：

- 从 fake RAG/fallback 数据整理为可验证的上传、入库、检索、引用链路。
- embedding provider 与模型 provider 解耦，降低不同模型供应商切换成本。
- 明确区分 mock embedding 和真实 embedding，避免把本地测试向量夸大为真实语义效果。

## 全栈开发岗位版

项目名称：Jrunmall 全栈电商与 AI 商家端系统

技术栈：Java/Spring Boot、Python/FastAPI、Vue3/Vite/Element Plus、MySQL、Redis、PostgreSQL、pgvector、Docker Compose、Vitest、Pytest、JUnit。

项目描述：项目覆盖用户端商城、商家端后台、Java 后端、Python AI 服务、本地 Docker 依赖和测试文档。用户端完成商品到订单的最小闭环，商家端完成商品管理、订单查看、知识库管理和 AI 文案生成。

项目职责：

- 搭建并整理用户端商品列表/详情、购物车、结算、订单、地址、秒杀入口等页面和接口联调。
- 搭建并整理商家端商品管理、普通订单、秒杀订单、知识库管理、AI 工作台等页面。
- 维护 Java 后端与 Vue 前端的 API 边界，使用 Vite proxy 对接本地服务。
- 接入 Python AI 服务，实现知识库导入、文案生成和引用来源前端展示。
- 整理 README、启动文档、安全检查文档、面试问答和 GitHub 上传说明。

项目亮点：

- 覆盖前端、后端、AI 服务和本地基础设施的端到端开发链路。
- 商家端 AI 工作台不是静态演示，能传递模型选择和知识库 ID，并展示 RAG 命中来源。
- 测试覆盖前端 Vitest、Python Pytest 和 Java JUnit 的核心模块。
